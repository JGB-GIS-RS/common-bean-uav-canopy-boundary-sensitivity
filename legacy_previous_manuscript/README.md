# Legacy previous-manuscript material

This directory preserves data, scripts, documentation, and derived outputs from an earlier exploratory manuscript focused on nitrogen-gradient and UAV–yield relationships.

These files are retained for provenance only and are **not part of the analytical workflow of the current manuscript**:

**Direction-Dependent Sensitivity of UAV-Derived Vegetation Indices to Canopy Boundary Definition in Common Bean**

Legacy material includes the harvest-enriched master dataset, field-harvest table, its data dictionary, UAV–yield/N association outputs, final-yield workflow, and the earlier R6 spatial-characterization workflow.

The current manuscript uses `derived/canopy_summary_by_plot.csv` for the baseline and the active `derived/boundary_sensitivity/` and `derived/radial_background/` products.
