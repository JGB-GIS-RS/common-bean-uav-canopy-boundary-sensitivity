# Legacy previous-manuscript material

This directory preserves scripts and derived outputs used for an earlier exploratory manuscript focused on nitrogen-gradient and UAV–yield relationships.

These files are retained for provenance only. They are **not part of the analytical workflow of the current manuscript**:

**Direction-Dependent Sensitivity of UAV-Derived Vegetation Indices to Canopy Boundary Definition in Common Bean**

In particular, the current manuscript does not use the legacy UAV–yield correlations, final-yield figure, N-rate association tables, or the earlier R6 spatial-characterization figure as analytical evidence.
