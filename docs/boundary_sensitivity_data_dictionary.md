# Boundary-Sensitivity Data Dictionary

This document describes the principal analysis-ready tables used by the current manuscript.

## Boundary perturbation

### boundary_perturbation_observations.csv
One record per plot × UAV acquisition × vegetation index × perturbation level.

Key fields include:
- `flight`, `date`, `growth_stage`
- `subplot`
- `index`
- `perturb_cm` (−3, −2, −1, 0, +1, +2, +3)
- `mean_index`
- `n_valid_pixels`
- `baseline_mean`
- relative spectral change from baseline

### boundary_geometry_qa.csv
One record per plot × UAV acquisition × perturbation level.

Contains:
- baseline/original mask area;
- perturbed mask area;
- proportional area change;
- geometric QA fields used to verify the effective consequences of nominal centimetre perturbations.

### crossplot_overlap_qa.csv
QA table documenting overlap checks used to ensure that dilation does not claim canopy assigned to another plot.

### baseline_reproduction_check.csv
Compares the d = 0 spectral extraction from Script 09 with the baseline extraction previously generated by the core canopy workflow.

## Normalized response

### normalized_boundary_response_observations.csv
Merged geometric and spectral response table containing:
- `delta_mask_area_pct`;
- `delta_index_pct`;
- plot, stage, index, and perturbation identifiers.

This is the principal observation-level input to normalized sensitivity and robustness calculations.

### normalized_boundary_sensitivity_by_plot.csv
Combined through-origin beta estimates by plot × stage × index. The combined beta is retained as a supporting metric.

### normalized_boundary_sensitivity_summary.csv
Descriptive summaries of the combined beta estimates.

## Direction-specific sensitivity

### directional_beta_by_plot.csv
Primary plot-level sensitivity table.

Key fields include:
- `beta_erosion`, `abs_beta_erosion`;
- `beta_dilation`, `abs_beta_dilation`;
- corresponding 1–2 cm sensitivity estimates;
- through-origin fit diagnostics;
- directional asymmetry and dilation-to-erosion ratio.

There are 75 plot × stage × index records.

### directional_beta_summary.csv
Stage × index summaries across P1–P5.

## Robustness

### directional_robustness_range_by_plot.csv
Plot-level comparison of direction-specific sensitivities estimated from 1–2 cm versus 1–3 cm perturbations.

### directional_robustness_range_summary.csv
Stage × index × direction summaries of perturbation-range sensitivity.

### directional_robustness_leave_one_subplot_out.csv
Results of sequentially omitting P1–P5 when calculating direction-specific aggregate sensitivity.

### directional_robustness_leave_one_subplot_out_summary.csv
Summary influence diagnostics across leave-one-plot-out runs.

The non-directional `robustness_*.csv` files are retained as supporting combined-beta diagnostics.

## Radial non-canopy analysis

### radial_ring_observations.csv
One record per plot × UAV acquisition × vegetation index × external ring.

Ring intervals:
- 0–5 cm
- 5–10 cm
- 10–15 cm
- 15–20 cm

All segmented canopy from P1–P5 is excluded from the rings.

### radial_ring_summary.csv
Stage × index × ring descriptive summaries across P1–P5.

### radial_gradient_by_plot.csv
Plot-level radial slopes and diagnostic quantities.

### radial_gradient_summary.csv
Stage × index summaries of the radial gradients.

## Statistical interpretation

These tables support descriptive sensitivity analysis. Perturbation levels and external rings are not independent biological replicates. The five plots are the spatial observational units.
